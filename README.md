# QR Code Studio

A browser-only React QR generator/designer implementing URL, text, email, phone and Wi-Fi QR types; live preview; presets; size/colors/error correction/margin controls; validation; scan-reliability warnings; PNG download; copy; and localStorage history.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.

## Build

```bash
npm run build
```

Deploy the resulting project to Vercel or Netlify. No backend or environment variables are required.
